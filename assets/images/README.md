# Image Assets

This directory should contain image files for the restaurant website.

## Required Images

### Menu Items
Place menu item images in `uploads/menu/` directory with meaningful names.

### Gallery Images
Place gallery images in `uploads/gallery/` directory.

### Category Images
Place category images in `uploads/categories/` directory.

## Placeholder Images

For development, you can use placeholder images from services like:
- Unsplash (https://unsplash.com)
- Lorem Picsum (https://picsum.photos)
- Placehold.co (https://placehold.co)

## Image Specifications

- **Menu Items**: 400x300px recommended
- **Gallery**: 800x600px recommended  
- **Categories**: 600x400px recommended
- **File Format**: JPG, PNG, or WebP
- **File Size**: Under 500KB recommended for performance

Upload actual images through the admin panel for menu items, categories, and gallery.
